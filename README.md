
# Employee Management System – SQL Project

## Project Overview

The Employee Management System is a relational database project developed using **MySQL** to manage and analyze employee-related information.

The system manages employee details, departments, job roles, salaries, bonuses, qualifications, leaves, and payroll.

## Objectives

- Create a structured employee management database
- Manage employee and department information
- Analyze salaries and bonuses
- Track employee qualifications and leaves
- Analyze payroll information
- Generate meaningful business insights using SQL

## Database Tables

The project contains six interconnected tables:

1. **JobDepartment** – Department and job role details
2. **SalaryBonus** – Salary and bonus information
3. **Employee** – Employee personal and job details
4. **Qualification** – Employee qualification details
5. **Leaves** – Employee leave records
6. **Payroll** – Payroll and payment information

## Business Analysis

The project analyzes questions such as:

- How many unique employees are in the system?
- Which departments have the highest number of employees?
- What is the average salary per department?
- Who are the top 5 highest-paid employees?
- What is the total salary expenditure?
- Which departments have the most job roles?
- Which employees have the most qualifications?
- Which employees have taken the most leaves?
- Which department receives the highest total bonuses?
- How are employees ranked by salary within each department?

## Key Findings

- The database contains **60 unique employees**.
- Finance and IT have the highest number of employees, with **9 employees each**.
- Legal has the highest average salary among the departments.
- Total annual salary expenditure is **₹5,18,52,000**.
- Employee salary ranking was performed both company-wide and within departments.
